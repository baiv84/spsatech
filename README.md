# Техподдержка

Система заявок в техподдержку для сотрудников учебного заведения: сотрудник сообщает
о проблеме с компьютером из Android-приложения (описание + фото), техподдержка
отвечает и ведёт заявку в веб-панели.

## Состав

| Часть | Технологии | Где |
|---|---|---|
| Android-приложение | Kotlin, Jetpack Compose, Retrofit, Coil, Firebase Cloud Messaging | `app/` |
| Сервер и веб-панель | Go (stdlib `net/http`, `html/template`), PostgreSQL (pgx) | `server/` |
| Развёртывание | Docker Compose, nginx, Let's Encrypt | `server/deploy/` |

## Возможности

- **Приложение:** вход по логину и паролю, заявки с фото (камера/галерея), переписка,
  выбор подразделения, push-уведомления об ответах и смене статуса, самообновление
  со страницы скачивания (в т. ч. обязательное).
- **Веб-панель:** очередь заявок с фильтрами и поиском, статусы и исполнители,
  история заявки, учётные записи сотрудников (временные пароли, блокировка),
  отчёты по подразделениям и исполнителям с выгрузкой в Excel.
- **Сервер:** bcrypt + JWT с отзывом токенов при смене пароля, ограничение попыток входа,
  CSRF-защита панели, проверка типа загружаемых файлов по содержимому,
  очередь push-уведомлений в PostgreSQL, синхронизация сотрудников из внешней
  кадровой системы (только чтение), публичная страница скачивания APK с QR-кодом.

## Локальный запуск

Сервер (нужны Go и Docker):

```sh
cd server
docker compose up -d                      # PostgreSQL на 127.0.0.1:5442
cp .env.example .env                      # и задайте JWT_SECRET: openssl rand -hex 32
set -a && . ./.env && set +a
go run ./cmd/helpdesk create-user -login admin -name "Администратор" -role admin   # пароль спросит
go run ./cmd/helpdesk serve               # http://localhost:8091/panel/
```

Приложение: откройте проект в Android Studio и запустите на эмуляторе.
В debug-сборке на экране входа можно выбрать сервер: локальный (`10.0.2.2:8091`) или боевой.
Для push-уведомлений нужен свой `app/google-services.json` из Firebase Console.
